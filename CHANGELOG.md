## Balam.AI 17  •  2026-04-23

What's new — **The Family Health Vault + AI Doctor** (strategic reframe):

**The Vault (primitive #1)**
• New `/vault` screen — per-member timeline of medical documents
• Upload prescriptions, labs, doctor's notes, vaccination cards as
  photo or PDF. Claude Sonnet 4.6 Vision auto-extracts type, provider,
  date, diagnoses, medications, follow-up date + flags for review.
• Firestore `vault/{uid}/items` with owner-only rules; extraction
  fields are server-write-only via `onVaultItemCreated` trigger.
• Live "Reading…" → "Processed" status, usually in 5–15 seconds.

**Grounded AI Doctor (primitive #2)**
• Every AI chat call now retrieves the top-3 relevant vault items
  for the selected member (keyword overlap 70% + recency 30%) and
  injects them into the system prompt. Claude cites the date +
  provider when it uses the record.
• Graceful degrade — retrieval is guarded by a 1200ms timeout and
  silently skipped on any failure. Chat never blocks on the vault.

**Family viral loop (acquisition)**
• New Add Member sheet with name / role chips / birth date, trilingual.
• After saving, a WhatsApp invite dialog opens — one-tap "Send on
  WhatsApp" with a pre-filled trilingual message.
• Family Completeness card on Today self-surfaces when the account
  has fewer than 2 members and self-hides once it does.

**Pharmacy directory (primitive #4)**
• New `/pharmacies` screen — 5 seeded Bishkek pharmacies + 1 NYC
  diaspora chain. Call / WhatsApp buttons per pharmacy; badges for
  hours / delivery / photo-Rx accepted.
• Vault prescription items now show a "Send to a pharmacy" button.
  Tap → pick a pharmacy → WhatsApp opens with pre-filled message
  including extracted medications + the Rx photo URL. We never
  process the order.

**Member-centric Today**
• Greeting adapts to selected member: pregnancy week for a pregnant
  child, "Name, X mo" for a baby, "Hi, Timur" + "You" for self,
  "Name + role label" for adult relatives.
• Baby/pregnancy focus/activity/tracking/worry/insight/product cards
  only render when the selected member is a child in a parenting
  stage. Adult members get a clean "Ask Balam about {name}" shortcut
  that opens AI chat with the vault pre-loaded.

**Localization pass**
• `ParentingStage.label` was hardcoded English and leaked into 5
  screens. Added trilingual `labelFor(lang)` extension and fixed
  children / profile / stage-selection / marketplace / my-child.
• 7 hardcoded English strings in the old Add Member flow localized
  to RU/KY.

**Plumbing**
• Firestore rules extended: `vault/{uid}/items` (owner read/write),
  `clinical_audit/*` (owner read, server write, never deletable),
  `emergencies/*` (owner read, user ack only).
• Cloud Functions shipped: `onVaultItemCreated` (Vision ingest),
  `submitBoxReading` (tier classifier with client-supplied member
  fallback), `proactiveNoticesScheduled` (daily 7am UTC).
• Dart client `vault_provider.dart` + `box_service.dart` +
  `family_invite.dart` all trilingual.
• MD advisor artifacts drafted in `docs/clinical-advisors/`: outreach
  for Jane Mone NP (CMO ask) + Prof. Uzakbaev (KG ask + 2 MD intros),
  bilingual EN/RU LOI template, Scope-of-Practice v0.1.

All three pieces — Vault, grounded AI, directory — are the defensible
moat. Balam Box hardware path (build 17-local) is re-scoped as a

stays in the repo but is gated behind a future paywall.
